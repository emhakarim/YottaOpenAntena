# Handover - 2026-09-23, 10:05 Asia/Jakarta

One defect broke **every** FDTD job of the night. It is now fixed and **proved by a run**, CI is green,
and the queue is relaunched. This page is the summary; the evidence lives in `yottakomen.md` §42-§43 and
`docs/incident-2026-09-22-heavy-runs.md`.

## 1. What failed, and the single cause

| Job | Attempt 1 (22 Sep, 22:13) | Attempt 2 (23 Sep, 00:00-02:00) |
|---|---|---|
| `k1c` port_refine A/B, 1e-4/400k | killed by the harness 3600 s default at 36-55 % | FDTD finished (3743 s / 5425 s), then `UnboundLocalError: port` -> **no s11.csv** |
| `k2c` loss validation, 3 cases | same | same (2859 / 5954 / 5962 s) |
| `b1s1` ground-margin swap | same | same (6082 / 6280 s) |
| `B2` coplanar feed A/B | probe arms died after 3230 s; line arms never started | probe arms died again (2469 / 2408 s); line arms never started |
| `arr2` 2x2 coupling S-matrix | **passed end to end** (4 ports, 101 points each, ~250-360 s per port) | not repeated |

**Cause (Python scoping, not physics).** In the generated deck the port object is created at module
scope, but an assignment inside `main()` - the attempt-1 hotfix `port = driven` - makes `port` a *local*
of `main()`. The probe path never binds that local, so the post-processing read was unbound, and the
failure always landed **after** the FDTD was paid for. Attempt 1's hotfix addressed the symptom
(`_s11_port`) while still reading the shadowed name, and the text-based regression test could not see it -
exactly what the review note in `yottakomen.md` §43 warned about, written before attempt 2 ran.

## 2. The fix in this tree

* `openantenna/solvers/openems.py`
  * the shadowing assignment inside `main()` is gone;
  * the s11 port is resolved per branch, and the single-port read goes through `globals()` with a
    **fast-fail guard** - a malformed deck now fails in the first second instead of after an hour;
  * the NF2FF accepted-power line reads the resolved port (`_s11_port`), not the shadowed name.
* Tests now pin the **cause**, not the symptom: `tests/test_openems_gen.py` (no `port = driven`, the
  guard must exist, no bare `port.uf_` read) and `tests/test_port_matrix.py` (no shadowing), each with
  the history written into the docstring.
* **Runtime proof** - the step text tests cannot take: the B2 probe deck was re-rendered with the fix
  and run to the full 400k-step cap; it wrote `s11.csv` (9470 B) at 09:59. The line deck was running at
  the time of writing. Suites: **374 tests OK (CI mode, 32 skipped)** and **372 passed (full)**.
